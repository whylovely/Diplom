# Система учёта личных финансов

Кроссплатформенное клиент-серверное приложение для учёта личных финансов, разработанное в рамках выпускной квалификационной работы.

Приложение предоставляет инструменты для ведения бюджета, управления счетами, контроля обязательств, анализа финансовых операций и синхронизации данных между локальным клиентом и удалённым сервером.

---

# Основные возможности

## Управление счетамиx

- создание и редактирование счетов;
- поддержка мультивалютности;
- автоматический пересчёт балансов;
- отображение актуального остатка срxwедств.

## Управление категориями

- создание пользовательских категорий;
- разделение доходов и расходов;
- группировка операций по категориям.

## Финансовые операции

- доходы;
- расходы;
- переводы между счетами;
- реализация принципа двойной записи.

## Работа с обязательствами

- учёт долгов и кредитов;
- контроль сроков исполнения;
- отображение просроченных обязательств.

## Отчётность

- динамика расходов и доходов;
- анализ по категориям;
- обороты по счетам;
- баланс на выбранную дату;
- визуализация данных при помощи диаграмм.

## Экспорт данных

Поддерживается экспорт отчётов в:

- Excel (.xlsx);
- CSV;
- TXT.

## Валютные курсы

Получение актуальных курсов:

- фиатных валют через ЦБ РФ;
- криптовалют через CoinGecko.

## Синхронизация

- локальная работа без подключения к интернету;
- хранение данных в SQLite;
- двусторонняя синхронизация с сервером;
- разрешение конфликтов при обновлении данных.

## Аутентификация

- регистрация пользователей;
- вход по JWT-токену;
- refresh-токены;
- роли User и Admin;
- блокировка пользователей администратором.

# Технологический стек

## Клиентская часть

| Компонент    | Технология            |
| ------------ | --------------------- |
| Язык         | C# 12                 |
| Платформа    | .NET 8                |
| UI           | Avalonia UI 11.3.11   |

| Локальная БД | SQLite                |
