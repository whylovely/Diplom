# Справочник по коду: C#, MVVM и Avalonia UI

## 1. Архитектура MVVM (CommunityToolkit.Mvvm)

* **`ObservableObject`**
Базовый класс для ViewModel. Реализует интерфейс `INotifyPropertyChanged`, который отвечает за уведомление пользовательского интерфейса (UI) об изменении данных, чтобы экран обновлялся автоматически.
* **`[ObservableProperty]`**
Атрибут для приватного поля (в `partial` классе), который с помощью кодогенератора создает публичное свойство с готовой логикой уведомления UI. Избавляет от написания шаблонного кода (boilerplate).
* **`[NotifyPropertyChangedFor(nameof(PropertyName))]`**
Атрибут для обновления *зависимых свойств*. Говорит UI: «Если изменилось текущее поле, обнови на экране еще и другое вычисляемое свойство (например, текст статуса или доступность кнопки)».
* **Перехватчики свойств (`partial void OnNameChanged`)**
Скрытые методы, которые генерируются вместе с `[ObservableProperty]`. Позволяют добавить кастомную логику (например, вызов других уведомлений) в момент, когда свойство получает новое значение.
* **`[RelayCommand]`**
Атрибут, превращающий обычный метод в объект команды (`ICommand`), которую можно привязать к кнопке в интерфейсе (XAML/AXAML). Поддерживает асинхронность (`Task`).
* **`[RelayCommand(CanExecute = nameof(PropertyName))]`**
Связывает команду с логическим свойством. Кнопка будет активна только в том случае, если свойство (например, `hasSelectedRow`) возвращает `true`. Защищает от неверных действий пользователя.

## 2. Структуры данных и модификаторы C#

* **`Guid?`**
Nullable-тип уникального идентификатора. Может хранить либо значение `Guid`, либо `null`. Удобно для представления необязательных связей в базе данных или невыбранных элементов интерфейса.
* **`enum` (Перечисления)**
Набор именованных констант (под капотом — числа). Делает код самодокументируемым, избавляя от "магических чисел" (например, `TxKindChoice.Expense` вместо `0`). Гарантирует типобезопасность.
* **`record` (Записи)**
Специальный тип для хранения данных. Отличается от классов тем, что сравнивается по значению (а не по ссылке), имеет очень краткий синтаксис и по умолчанию ориентирован на неизменяемость данных (мутации делаются через ключевое слово `with`). Идеален для DTO.
* **`sealed` (Запечатанный класс)**
Модификатор, запрещающий наследование от данного класса. Защищает архитектуру от непредсказуемых расширений и дает микрооптимизацию производительности.
* **`partial` (Частичный класс)**
Позволяет разбить код одного класса на несколько файлов. Критически важен для работы генераторов исходного кода (MVVM) и UI-фреймворков (Avalonia), где часть кода пишет программист, а часть дописывает компилятор.

## 3. События, Делегаты и Коллекции

* **`Action?` и `Changed?.Invoke()**`
`Action` — делегат (указатель на метод) без параметров. Знак вопроса означает, что на событие может быть никто не подписан. Вызов `?.Invoke()` безопасно запускает событие: если подписчики есть — метод выполняется, если нет — код идет дальше без ошибки `NullReferenceException`.
* **`RaiseChanged()`**
Стандартная инкапсуляция: вспомогательный приватный/защищенный метод, внутри которого "прячется" вызов события (чтобы событие нельзя было вызвать снаружи класса напрямую).
* **`Func<string, string, decimal>`**
Делегат, представляющий метод, который принимает две строки (например, коды валют) и возвращает число (курс обмена). Отличный способ передать логику расчета внутрь другого метода.
* **`IReadOnlyList<T>`**
Интерфейс коллекции, которую можно только читать (по индексу) и перечислять, но нельзя изменять (добавлять/удалять элементы). Защищает данные от случайной модификации извне.
* **`IDictionary<TKey, TValue>`**
Словарь (хэш-таблица) для хранения данных в виде пар "Ключ-Значение". Обеспечивает мгновенный поиск (например, поиск курса валюты по её коду).

## 4. Синтаксис и Логика

* **Null-forgiving оператор (`!`)**
Например, `toAccount!.CurrencyCode`. Сообщает компилятору: «Я как разработчик гарантирую, что здесь `toAccount` не равен `null`, игнорируй предупреждение системы безопасности типов».
* **Логическое ИЛИ (`||`)**
Например, `choice == DebtRepayment || choice == DebtReceive`. Условие выполняется, если истинна хотя бы одна из частей.

## 5. Работа с Базой Данных (SQLite / SQL)

* **`DBNull.Value`**
Специальный объект, представляющий SQL-значение `NULL`. Обычный C# `null` базы данных не понимают, поэтому при записи "пустоты" в таблицу нужно передавать именно `DBNull.Value`.
* **`(object?)template.AccountId?.ToString() ?? DBNull.Value`**
Цепочка безопасного извлечения данных для БД: берется ID (если есть), переводится в строку, приводится к типу `object` (требование драйвера БД), а оператор `??` гарантирует, что если исходный ID был равен `null`, в базу запишется честный SQL `NULL`.

## 6. Пользовательский интерфейс (Avalonia UI и LiveCharts2)

* **`ApplicationLifetime`**
Паттерн Avalonia для проверки среды запуска. Приведение к `IClassicDesktopStyleApplicationLifetime` дает доступ к десктопным функциям (управление главным окном `MainWindow`, программное закрытие `Shutdown()`, аргументы командной строки).
* **`Window _window`**
Ссылка на текущее окно приложения. В MVVM сохраняется (через DI/конструктор) для того, чтобы иметь возможность открывать дочерние диалоговые окна поверх родительского (`ShowDialog()`).
* **`Geometry.Parse("M1... Z")`**
Программное создание векторной иконки (SVG Path Data) из текстовой строки. `M` — переместить перо, `L` — нарисовать линию, `Z` — замкнуть фигуру. Вектор не теряет качество при масштабировании.
* **LiveCharts2 (Графики)**
* `LineSeries<decimal>`: Линия графика, привязанная к массиву числовых значений (доходов/расходов).
* `Stroke` / `Fill`: Настройка цвета линии и полупрозрачной заливки под ней с использованием движка `SkiaSharp`.
* `LabelsPaint` / `SeparatorsPaint`: Настройка оформления осей графика (цвет текста подписей и линий фоновой сетки).



## 7. Безопасность и Сеть (Опционально / К удалению)

* **`PasswordHasher<UserEntity>`**
Криптографический инструмент (`Identity`) для необратимого хеширования паролей перед сохранением в БД (использует "соль" и алгоритм PBKDF2). Необходим для клиент-серверной архитектуры, но избыточен в полностью локальном приложении без системы авторизации.
* **Блок `try-finally` (Обновление токена)**
Паттерн перехвата HTTP-запросов. Если запрос падает с ошибкой доступа, делается попытка обновить JWT-токен (`TryRefreshAsync()`). Блок `finally` гарантирует, что флаг состояния (`_isRefreshing = false;`) сбросится в любом случае, предотвращая зависание приложения.
