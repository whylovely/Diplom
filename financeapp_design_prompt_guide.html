Что делать
Один фон страницы — #FAFAFA. Карточки белые #FFFFFF. Контраст через разницу поверхностей, а не цвет.
Рамки карточек — 0.5px #E5E7EB. Скругление — 12px. Никаких теней (ни drop-shadow, ни box-shadow).
Иконки только outline-стиль, stroke 1.5px, без заливки. В кружке 40px с фоном rgba(31,41,55,0.08).
Суммы и числа — моноширинный шрифт (SF Mono / Roboto Mono / Consolas). Это читаемость и ощущение банковского терминала.
Положительные суммы — #059669. Отрицательные — #DC2626. Только для числовых значений, больше нигде.
Разделители между элементами списка — 0.5px #E5E7EB, только горизонтальные. Без боковых рамок у строк.
Выравнивание суммы — вправо. Выравнивание метки и названия — влево. Никогда по центру в списках.
Поля ввода: фон #F9FAFB, рамка 0.5px #E5E7EB, в фокусе рамка 1px #1F2937. Без цветной подсветки.
Что не делать
Никаких градиентов — ни фоновых, ни на кнопках, ни на карточках.
Никаких теней — ни у карточек, ни у кнопок, ни у модалок. Только рамка.
Никаких цветных заголовочных полос (header с зелёным/синим фоном под статус бар).
Никаких засечковых шрифтов — только sans-serif для всего интерфейса.
Никаких эмодзи вместо иконок — только SVG outline.
Не использовать акцентный цвет как фон целых секций — только точечно для числа или иконки.
Не красить всю строку транзакции в зелёный/красный — только сумму.
Не делать кнопки с полностью залитым фоном — только тонкая рамка или белый фон + рамка #1F2937.
